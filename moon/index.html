        Sync with GitHub

        MOON saves your data as one file next to the app in your GitHub repository, so every machine shows the same week. Set this up once on each machine. The file is as public as the rest of the site.

        1. In GitHub, open Settings, Developer settings, Fine-grained tokens. Make a token that can reach only your site repository, with Contents set to Read and write.
        2. Paste it below. The repository and file are already filled in.
