        Sync with GitHub

        MOON saves an encrypted copy of your account in your site repository, so you can sign in from any machine. The file is unreadable without your password. Do this on each machine where you want changes to be saved to GitHub.

        1. In GitHub, open Settings, Developer settings, Fine-grained tokens. Make a token that can reach only your site repository, with Contents set to Read and write.
        2. Paste it below. The token stays on this device, encrypted.

        Change password

        Other machines pick up the new password the next time you sign in there. Use at least 10 characters.
